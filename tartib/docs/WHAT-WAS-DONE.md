# Tartib — что сделано

Tartib — веб-приложение для трейдера: калькулятор риска, журнал сделок, личные правила, статистика и «Цена дисциплины»
(сколько заработано по правилам и сколько потеряно из-за нарушений). Это не бот, не сигналы и не советы по инвестициям.

## Где что лежит

| Папка / файл | Что это |
|---|---|
| `app/` | Страницы сайта и серверные действия (`app/actions/`) |
| `components/` | Элементы интерфейса: кнопки, формы, графики, таблицы |
| `lib/` | Формулы калькулятора, проверка правил, статистика, проверка данных, переводы |
| `lib/i18n/dictionaries/` | Тексты на русском, узбекском и английском (`ru.json`, `uz.json`, `en.json`) |
| `services/ai/` | Сборка недельного отчёта (по правилам и через OpenAI при наличии ключа) |
| `supabase/migrations/` | SQL базы данных: таблицы, защита, лимиты тарифов, функции |
| `supabase/seed.sql` | Демо-данные: пользователь `demo@tartib.app`, пароль `demo12345` |
| `tests/` | Автотесты формул, статистики, CSV, AI-отчёта |
| `.env.example` | Образец настроек (ключи Supabase и др.) |

## Как запустить на своём компьютере

1. Установить Node.js (версия LTS) с nodejs.org.
2. В папке проекта: `npm install`
3. Скопировать `.env.example` в `.env.local` и вписать адрес и публичный ключ Supabase.
4. `npm run dev` и открыть http://localhost:3000
5. Проверки: `npm test`, `npm run lint`, `npm run build`

## Этапы

1. **Основа:** Next.js, Tailwind, три языка, светлая и тёмная тема, набор элементов интерфейса, лендинг, тарифы.
2. **Вход и база:** Supabase, регистрация, вход, выход, защита страниц, онбординг (имя, язык, валюта, счёт).
3. **Ядро:** правила, калькулятор с проверкой правил и оценкой X/10, журнал сделок с фильтрами, детали, правка, удаление.
4. **Аналитика:** Dashboard, статистика, графики, «Цена дисциплины», анализ эмоций.
5. **Полировка:** телефонная версия, пустые и ошибочные состояния, Настройки, Профиль, Terms и Privacy, SEO, демо-данные.
6. **AI-архитектура:** недельный отчёт, таблица `weekly_reports`, системный промпт без сигналов и прогнозов.
7. **Доработки по 15 предложениям** (см. ниже). Этап «выкладка на Vercel» ещё не делался.

## Что умеет сайт сейчас

- Регистрация, вход, выход, восстановление пароля, удаление аккаунта (нужна функция в базе, см. «Что осталось»).
- Правила 7 типов: максимум риска, минимум R:R, максимум плеча, обязательный стоп-лосс, максимум сделок в день,
  дневной лимит убытка, своё правило. Готовые примеры добавляются одним нажатием.
- Калькулятор: размер позиции, убыток, прибыль, R:R, экспозиция, маржа, лоты для Forex, целые акции; оценка X/10 только по твоим правилам;
  предупреждение «Эта сделка нарушает твои правила» (решение остаётся за пользователем); предупреждение, если маржа больше баланса;
  чек-лист перед сделкой.
- Журнал: фильтры, пагинация, стратегия, эмоция, нарушенные правила (по цифрам отмечаются автоматически), скриншот графика.
- Статистика: P&L, win rate, profit factor, средние прибыль и убыток, просадка, средний R; графики; календарь; анализ эмоций;
  «Цена дисциплины»; серия дисциплины.
- Экспорт и импорт сделок в CSV.
- Недельный отчёт (PRO). Панель владельца `/admin`.
- Установка на экран телефона (PWA).

## Тарифы

- **FREE:** до 30 сделок и до 5 правил (лимиты защищены в самой базе), статистика за 7 и 30 дней.
- **PRO:** без лимитов, статистика за всё время и по стратегиям, недельные отчёты. Оплата не подключена: PRO выдаёт владелец на `/admin`.

## Безопасность

- Защита на уровне строк (RLS) на всех таблицах: каждый видит только свои данные.
- Все данные проверяются на сервере (Zod). Пароли хранит только Supabase Auth.
- Секретный ключ service role нигде не используется. Пользователь не может сам выдать себе права владельца.
- Скриншоты в приватном хранилище, у каждого пользователя своя папка.

## Что осталось на стороне владельца

- Выполнить в Supabase SQL-функцию `delete_my_account` (текст в конце `supabase/migrations/20260104000000_plan_limits_and_account_deletion.sql`).
- Назначить себя владельцем после регистрации:
  `update public.profiles set is_admin = true where id = (select id from auth.users where email = 'ВАША_ПОЧТА');`
- Надёжные письма (своя почтовая служба в Supabase), вход через Google, ключ OpenAI, платёжный провайдер.
- Юридическая проверка текстов Terms и Privacy; контакт для связи.
- Этап выкладки на Vercel.

## Известные ограничения

- Одна валюта в общей статистике (берётся валюта первого счёта).
- Статистика считается в приложении, для десятков тысяч сделок понадобится вычисление в базе.
- Узбекские тексты написаны без носителя языка, их стоит проверить.
- Проверялось в Chromium (имитация телефона), настоящие iPhone и Safari не тестировались.

## Дополнение: достижения, цель месяца, карточка результата, быстрая запись

- Достижения (8 штук) и цель месяца по дисциплине на дашборде. Всё считается из журнала.
- Публичная карточка результата (профиль → «Поделиться результатом»): только доля сделок по правилам и серия, без денег и сделок. Ссылку можно выключить или заменить на новую.
- Быстрая запись сделки (`/trades/quick`): инструмент, направление, цены, объём, эмоция.
- Напоминание на дашборде, если сделок не было записано 3 дня и больше.
- База: миграция `20260107000000_goals_and_share.sql`.

- Проверено: все таблицы закрыты правилами доступа (RLS), чужие данные не читаются и не изменяются, администратором или PRO нельзя стать через запросы.

## Дополнение: Telegram-бот

- Бот `@tartibuk_bot` работает как функция Supabase (`supabase/functions/telegram-bot`), во Франкфурте рядом с базой.
- Токен и секреты бота лежат в закрытой таблице `bot_config`, в коде и в репозитории их нет.
- Привязка аккаунта: «Профиль» → «Telegram» даёт одноразовый код (15 минут).
- Команды: запись сделки сообщением, `/today`, `/reminders on|off`, `/unlink`, `/help`.
- Напоминания: раз в час по расписанию (pg_cron), только днём по времени пользователя и не чаще раза в 3 дня.
- Бот работает с правами сервиса, поэтому каждый его запрос к данным явно ограничен пользователем. Копии формул проверяет тест `tests/telegram-bot-sync.test.ts`.
- Функция выкладывается в Supabase отдельно от сайта.

## Дополнение: вход и регистрация по номеру телефона

- На страницах входа и регистрации есть кнопка «Войти или зарегистрироваться по номеру».
- Номер подтверждает Telegram-бот (кнопка «Поделиться номером»), SMS и платные сервисы не нужны.
- Если чат уже привязан к аккаунту или аккаунт с этим номером есть, человек входит в него. Иначе создаётся новый аккаунт, а чат сразу привязывается к боту.
- Принимается только свой номер (бот сверяет `user_id` контакта). Код входа одноразовый и живёт 10 минут.
- Если у аккаунта включена двухфакторная защита, после входа по номеру всё равно просят код.
- База: миграция `20260112000000_telegram_phone_login.sql`.

## Дополнение: новости рынка

- Страница `/news`: заголовки из открытых RSS-каналов (Cointelegraph, Decrypt, CoinDesk, Bits.media, ForkLog, Investing.com, MarketWatch, Gazeta.uz, Kun.uz). Бесплатно, ключи не нужны.
- Показываются только заголовок, источник, время и ссылка на оригинал, статьи открываются на сайтах источников.
- Фильтры: категория (крипто, рынки, Узбекистан) и язык (RU, EN, UZ).
- Ответы источников кэшируются Cloudflare на 10 минут; недоступный источник пропускается.
- Ссылки только http(s), без меток отслеживания; открываются с `noopener noreferrer nofollow`.
