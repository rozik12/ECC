# Tartib

Веб-приложение для трейдера: калькулятор риска, журнал сделок, личные правила, статистика и «Цена дисциплины».
Tartib — инструмент учёта и дисциплины. Он не даёт инвестиционных рекомендаций, торговых сигналов или гарантий прибыли.

## Запуск

```bash
npm install
cp .env.example .env.local   # впишите адрес и публичный ключ Supabase
npm run dev                  # http://localhost:3000
```

## Команды

- `npm run dev` — запуск для разработки
- `npm run build` — сборка (проверяет и типы)
- `npm run lint` — проверка кода
- `npm test` — автотесты формул и статистики

## База данных

SQL-миграции лежат в `supabase/migrations/` (применяются по порядку имён файлов).
Демо-данные: `supabase/seed.sql` (демо-пользователь `demo@tartib.app`, пароль `demo12345`). Не запускать на боевой базе.

## Структура

`app/` страницы · `components/` интерфейс · `lib/` расчёты, статистика, валидация, переводы · `types/` типы · `supabase/` база данных.
Переводы: `lib/i18n/dictionaries/{ru,uz,en}.json`. Новый язык = новый JSON + строка в `lib/i18n/config.ts`.
